# v2 targetability release notes

This release extends the original atlas/spatial/evolution package with the analyses used in the consolidated Nature Communications v8 manuscript.

Added:
- final cross-cancer FAP-only/DPP4-only state-program analysis;
- organ-concordant matched tumor-normal target-selectivity analysis;
- same-study malignant-versus-benign lung remodeling analysis;
- donor-level FAP abundance-versus-state analysis;
- primary-fibroblast versus other-cell FAP selectivity analysis;
- integrated non-composite targetability map;
- compact source-data exports for Figures 6-8 and Supplementary Figures S8-S9;
- SVG sources for new target-biology figures.

Provisional/debug scripts generated during quality-control checks are intentionally excluded.
