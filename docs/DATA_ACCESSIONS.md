# Public data resources

The release intentionally does not redistribute raw third-party datasets.

- CZ CELLxGENE Census: release 2025-11-08, Homo sapiens RNA primary data.
- GSE210616: TNBC Visium spatial transcriptomics; primary spatial validation cohort.
- GSE243275: breast-cancer spatial dataset with published histologic annotations; descriptive validation.
- GSE243022 and GSE246518: additional breast-cancer spatial resources used in descriptive/sensitivity analyses.
- UniProt and reference-genome annotations: curated S9-family protein and locus sequences used for evolutionary analyses.

Exact accession/provenance tables for the evolutionary sequence set are retained with the project audit files and should accompany the final archival release.
