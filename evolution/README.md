# Expanded evolution reproducibility package

This directory contains the final evidence set supporting manuscript Figure 5 and Supplementary Figures S1-S7.

Included:
- curated final alignments used for deep-S9, FAP/DPP4, DPP6/DPP10 and codon analyses;
- final IQ-TREE treefiles and reports for the main and sensitivity phylogenies;
- topology-test candidate trees and reports;
- synteny, reconciliation, ASR, selection and structure-distance tables;
- final PAML inputs/outputs including starting-value sensitivity runs;
- vector sources for Figure 5 panels A-G and Supplementary Figures S1-S7;
- figure legends, source-data map and interpretation notes.

Excluded deliberately:
- obsolete checkpoint1000 files;
- large raw proteome/search registries used only for candidate discovery;
- IQ-TREE checkpoint/model/cache files;
- multi-megabyte raw ASR `.state` matrices, because their summarized posterior probabilities and all input alignments/tree reports needed to regenerate them are included.
